Install Blind Path

ANDROID PHONE
  1. Open this website in Chrome.
  2. Tap the ⋮ menu, then Install app (or Add to Home screen).
  3. Tap Install. The Blind Path icon appears on your home screen and opens full screen.
IPHONE / IPAD
  1. Open this website in Safari.
  2. Tap the Share button, then Add to Home Screen.
  3. Tap Add. Open Blind Path from your home screen like any app.
WINDOWS / MAC / LINUX
  1. Open this website in Chrome or Edge.
  2. Click the install icon in the address bar (or menu → Install Blind Path).
  3. Click Install. It opens in its own window and gets a desktop shortcut.
